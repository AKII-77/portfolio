Project 01

Generative AI · Blue Team

Automated Phishing Response AI Agent

A generative AI agent that ingests EDR-flagged email, checks it against sender authentication, and closes the loop with automated containment — cutting the distance between a suspicious inbox and a cleared one.

  • Verifies sender authenticity by checking DKIM, SPF and DMARC on every ingested EDR email.
  • Cross-references indicators of compromise — IPs, URLs, attachments — against external threat intelligence feeds for fast malicious-activity calls.
  • Triggers automated response: tenant-wide email purges and new EDR blocklist entries, no manual hand-off required.
  • Closes the loop with automated summary reports and notifications for every affected user.

Project 02

Python & Regex · Detection

Automating Web Application Attack Analysis

A web interface built with Python and regex operations to catch application-layer attacks as they happen, then take the resulting indicators straight into open-source intelligence and static analysis.

  • Detects XSS, CSRF, RCE, token-based attacks, code/command injection and XML injection automatically.
  • Filters indicators of compromise — executables, webshells (.aspx, .php), hashes, IPs — out of the noise.
  • Checks every extracted IOC against OSINT sources and runs automatic static file analysis.
